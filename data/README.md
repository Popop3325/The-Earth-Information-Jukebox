# Дані

- `catalog.json`: список відео (id, назва, сторінка SVS). **Комітимо.**
- `raw/`: завантажені відео (`<id>.mp4`). **Не комітимо.**
- `features/`: результат `pipeline.run` (`<id>.json`). **Не комітимо**, бо кожен генерує локально. Якщо потрібно поділитися, можна прибрати це правило з `.gitignore`.

## Як отримати відео

1. Відкрийте сторінку `svs_page` з `catalog.json` (джерело: [EIC gallery](https://svs.gsfc.nasa.gov/gallery/earth-information-center/)).
2. У блоці **Download** оберіть MP4 з роздільністю 1080p або нижче. 4K не потрібне.
3. Збережіть файл як `data/raw/<id>.mp4` і впишіть пряме посилання в `video_url`, щоб інші могли завантажити те саме.
