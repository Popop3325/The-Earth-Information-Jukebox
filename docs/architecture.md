# Архітектура

```
data/raw/<id>.mp4 ──▶ pipeline/  (Python, OpenCV, ML)
                         │  кадри (sample_fps), crop + exclude-маска,
                         │  екстрактори: basic, landcover
                         ▼
               data/features/<id>.json   (фічі 0..1 у часі + keyframes з метриками)
                         │
                         ▼
                      sonify/  (Python)  + sonify/presets.json
                         │  фічі → партитура
                         ▼
                    score (JSON)  ── shared/schema/score.schema.json
                         │
                    backend/ (FastAPI)
      /api/videos  /api/score/<id>  /api/quiz/<id>  /media  /static
                         │
          ┌──────────────┴───────────────┐
   frontend/ (джукбокс)          frontend/game/ (гра)
          └──── frontend/player.js (ScorePlayer, Tone.js) ────┘
                    програє score синхронно з video.currentTime
```

## Головні рішення

1. **Уся «розумна» частина написана на Python:** фічі, ML і алгоритм сонифікації. Браузер нічого не вирішує, він лише **програє партитуру** синхронно з відео. Так троє людей на Python працюють без JavaScript.
2. **Партитура генерується на льоту** в `GET /api/score/<id>` з фіч і пресету. Змінили `presets.json` чи `score.py`, оновили сторінку і одразу чуєте результат.
3. **Партитура описана в часі ВІДЕО.** Тому сповільнене відео (як у грі) автоматично сповільнює і звук.
4. **Звук гібридний:**
   - **шари семплів** (птахи, вітер, дзвіночки), гучність яких іде за даними. Цей підхід узято з прототипу гри;
   - **синтез нот** (bell, pluck, pad, drum) за гамою й ладом.

## Pipeline

1. **Семплінг за часом:** `sample_fps` кадрів на секунду незалежно від FPS відео. Кадр зменшується до ширини 480 px.
2. **`crop` і `exclude`** з `data/catalog.json`: прибираємо чорні смуги, підписи років і логотипи. `exclude` перетворюється на маску, і фічі рахуються лише по ній.
3. **Екстрактори** (`pipeline/extractors.py`):
   - `basic`: яскравість, контраст, насиченість, «теплота», деталізованість, частка яскравих пікселів, рух, центр мас;
   - `landcover`: `green`, `built`, `water`, `cloud`. Зараз працює на правилах RGB, далі буде ML-класифікатор.
4. **Згладжування EMA** для неперервної музики. Метрики ключових кадрів (`keyframes`) беруться **без** згладжування.

## Сонифікація (`sonify/`)

Пресет (`sonify/presets.json`) описує:
- `layers`: семпл + фіча + діапазон, з яких виходить крива гучності;
- `voices`: інструмент + як часто звучить + звідки висота, сила й ймовірність ноти;
- `mode`: який лад, мажор чи мінор. Він залежить від фічі і змінюється лише на початку такту, з гістерезисом;
- `tempo_bpm`, `root`.

Генератор детермінований: однакові дані завжди дають однакову музику (фіксований `seed`).

## Гра (`frontend/game/`)

`GET /api/quiz/<id>` повертає ключові кадри (роки) і пари сусідніх років із правильною відповіддю на питання «де більше/менше <subject>». Налаштовується в каталозі, поле `quiz`. Гра питає, дає прослухати кожен рік, а за правильну відповідь відкриває уповільнений відрізок відео зі звуком.

## Відомі обмеження

- Відео Канкуна взяте не з EIC/SVS: це запис Google Earth Timelapse (Landsat). Для подачі потрібно або знайти джерело NASA, або чесно вказати походження.
- Правила `landcover` залежать від кольорового балансу знімка: у 2017–2018 роках «зелень» штучно зростає. Тому квіз рахується за `built`. Це виправить ML-класифікатор.
- Таймлапс триває лише близько 4 с, тому для музики його треба «розтягувати». У грі це робиться через `playbackRate`, у джукбоксі поки ні.
