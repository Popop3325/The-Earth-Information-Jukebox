# Архітектура

## Головне рішення

Фічі рахуємо **офлайн** (Python), а звук синтезуємо **в браузері в реальному часі** (Tone.js), синхронізуючи його з відео через `video.currentTime`.

Чому так:
- набір відео фіксований (ресурси NASA SVS), тож обробляти його наживо немає сенсу;
- користувач може міняти інструмент, гаму чи темп без запитів до сервера;
- аудіофайли для плейлиста можна відрендерити з тієї ж «партитури» (`Tone.Offline`).

## Pipeline

1. **Семплінг за часом.** Беремо `sample_fps` кадрів на секунду (за замовчуванням 5) незалежно від FPS відео. Кадр зменшуємо до ширини 480 px.
2. **Маска.** Прибираємо легенди, підписи й логотипи (`--crop` або маска для кожного відео).
3. **Фічі.** Значення нормалізуємо до 0..1 (див. `pipeline/features.py`).
4. **Згладжування.** Використовуємо EMA, щоб музика «не стрибала».
5. **Збереження.** Пишемо `data/features/<id>.json` за схемою `shared/schema/features.schema.json`.

## Два шари: фічі та маппінг

- **Фічі** описують, що є на кадрі. Це дані, їх рахує Python.
- **Маппінг** (`shared/mapping.json`) описує, як фіча впливає на звук. Його редагують ті, хто займається звуком, без зміни коду.

## Інтерполяція на фронтенді

- **Неперервні параметри** (гучність, фільтр, темп) інтерполюються лінійно між двома найближчими семплами за часом.
- **Дискретні параметри** (мажор/мінор, акорд) змінюються **лише на початку такту** і лише якщо нове значення тримається ≥ N секунд (гістерезис).
