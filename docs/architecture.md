# Архітектура

```
data/raw/ndvi_global.mp4  (NASA SVS 5544, 4096x2048, 1 кадр = 1 день)
        │
        ▼
pipeline/  (Python, OpenCV, ML)
   • кадри з частотою sample_fps (10/с = кожні 3 дні), до 900-ї дати (далі стоп-кадр)
   • crop: Північна Америка; exclude: Гренландія
   • ndvi.py: колір → NDVI за шкалою (Lab-таблиця), маски океан/сніг, зони, фронт весни
   • keyframes: 1-ше число кварталу з data/sources/ndvi_dates.txt
        │
        ▼
data/features/ndvi_north_america.json   ← ДАТАСЕТ (12 фіч × 300 точок)
        │
        ▼
sonify/  (Python) + sonify/presets.json ("vegetation")
        │  фічі → партитура
        ▼
score (JSON)  ── shared/schema/score.schema.json
        │
backend/ (FastAPI): /api/videos  /api/score/<id>  /api/quiz/<id>  /media  /static
        │
   ┌────┴─────────────────────────┐
frontend/ (джукбокс)        frontend/game/ (гра)
   └── frontend/player.js (ScorePlayer, Tone.js): програє score синхронно з video.currentTime
```

## Головні рішення

1. **Один відеофайл, регіон — це конфіг.** Північна Америка задається через `crop` + `geo` у `data/catalog.json`. Інший материк = новий запис з тим самим `raw_file`.
2. **Звук рахує Python, браузер лише програє.** Партитура генерується на льоту в `GET /api/score/<id>`: змінили `presets.json`, оновили сторінку, почули результат.
3. **Партитура описана в часі ВІДЕО.** Сповільнене відео (у грі) автоматично сповільнює звук.
4. **Звук гібридний:** шари семплів (птахи, вітер, дзвіночки), чия гучність іде за даними, і синтез нот (bell, pluck, pad, drum) за гамою й ладом.

## Датасет (фічі NDVI)

Опис кожної фічі: `pipeline/ndvi.py` → `NDVI_FEATURES`.

| Фіча | Що означає | Діапазон у даних |
|---|---|---|
| `ndvi_mean` | середній NDVI суші | 0.25 (зима) – 0.67 (серпень) |
| `green_share` / `bare_share` | частка густої зелені / голої землі | |
| `snow_share` | частка снігу | 0.59 – 0.002 |
| `green_front_lat` | до якої широти дійшла зелень | ~25° (березень) – ~70° (серпень) |
| `green_up_rate` | весна (> 0.5) чи осінь (< 0.5) | |
| `ndvi_centroid_x` | зелень на заході (0) чи сході (1) | |
| `zone_north/east/west/south` | NDVI по 4 зонах | південь у протифазі (пік у вересні–листопаді) |
| `ndvi_spread` | однорідно чи плямами | |

**Обмеження:** у шкали SVS немає чисел, тому NDVI тут **відносний** (0 = низ шкали, 1 = верх).

## Сонифікація (`sonify/`)

Пресет описує:
- `layers`: семпл + фіча + діапазон, з яких виходить крива гучності;
- `voices`: інструмент + як часто звучить + звідки висота, сила й ймовірність ноти;
- `mode`: лад (мажор/мінор) від фічі, змінюється лише на початку такту, з гістерезисом;
- `tempo_bpm`, `root`.

Генератор детермінований (фіксований `seed`).

## Гра (`frontend/game/`)

`GET /api/quiz/<id>`: ключові кадри (квартали) і пари «де більше/менше зелені». Пари з різницею менше `min_diff` пропускаються, бо на слух їх не розрізнити.
