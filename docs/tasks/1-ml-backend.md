# №1: ML + Backend (капітан)

**Твої файли:** `pipeline/`, `backend/`, `requirements.txt`
**Не чіпай:** `sonify/` (№2), `frontend/` (№4, №5). Додав нову фічу? Повідом №2.

## Контекст
- Відео: NASA SVS 5544 (NDVI), `data/raw/ndvi_global.mp4`. Регіон: Північна Америка (`crop` + `geo` у `data/catalog.json`).
- `pipeline/ndvi.py` переводить колір у NDVI за шкалою і рахує 12 фіч: середній NDVI, частки зелені/голої землі/снігу, фронт весни, швидкість позеленіння, 4 зони.
- `backend/main.py`: `/api/videos`, `/api/features/<id>`, `/api/score/<id>`, `/api/quiz/<id>`.

```bash
.venv/bin/python -m pipeline.run ndvi_north_america
.venv/bin/uvicorn backend.main:app --reload --reload-exclude '.venv/*'
```

## Задачі

### MVP
1. **Перевірка якості датасету:** скрипт `pipeline/inspect.py`, що малює графіки фіч у часі (matplotlib → PNG) і накладає маску NDVI на кадр. Без нього ми «не бачимо» дані.
2. **Згладжування «шуму хмар»:** NDVI NRT щоденний, хмари дають провали. Медіанний фільтр за кілька днів перед EMA.
3. **Валідація** результату за `shared/schema/*.schema.json` (`jsonschema`).

### ML (головна «фішка» для журі)
4. **Кластеризація екорегіонів (unsupervised ML):** для кожного пікселя суші беремо часовий ряд NDVI (300 точок) → **KMeans** (5–8 кластерів) → отримуємо регіони зі схожою «сезонною поведінкою» (тундра, бореальний ліс, ліси сходу, прерії, пустелі, тропіки). Кожен кластер стає окремою фічею й окремим голосом у музиці. Це замінює ручні `zone_*` на зони, знайдені з даних.
   - результат: `pipeline/models/ecoregions.npy` (мапа кластерів) + картинка для презентації;
   - фічі `cluster_0..N` = середній NDVI кластера в кадрі.
5. **Аномалії:** порівняти той самий день різних років (2024 vs 2025 vs 2026). Фіча `ndvi_anomaly` = відхилення від середнього за цей день. Весна 2026 помітно запізнюється, тож це історія для звуку («тривога»).
6. **Фенологія:** дата «зеленого старту» для кожної зони (коли NDVI перетинає поріг), щоб подія `green_up_event` давала окремий звук.

### Покращення
7. **Інші материки:** перевірити, що `crop` + `geo` для Європи або Південної Америки дають адекватні фічі (`zone_*` залежать від широт Північної Америки, тому їх треба параметризувати).
8. **Кеш партитури в backend**, щоб не перебудовувати її на кожен запит.
