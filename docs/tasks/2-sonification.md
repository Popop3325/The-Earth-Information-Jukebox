# №2: Алгоритм сонифікації (Python)

**Твої файли:** `sonify/` (`score.py`, `presets.json`, `run.py`), `shared/schema/score.schema.json`
**Не чіпай:** `pipeline/` (нові фічі проси в №1), `frontend/` (зміни формату партитури узгоджуй з №4)

## Контекст
- Вхід: датасет `data/features/ndvi_north_america.json`, 12 фіч NDVI кожні 3 дні (опис: `pipeline/ndvi.py`, таблиця в `docs/architecture.md`).
- Вихід: **партитура** (`shared/schema/score.schema.json`): `layers` (семпли з кривою гучності), `events` (ноти), `keyframes`.
- Пресет: `sonify/presets.json` → `vegetation`.
- `GET /api/score/<id>` викликає `build_score()` на льоту: змінив, оновив сторінку, почув.

```bash
.venv/bin/python -m sonify.run ndvi_north_america     # шари, к-сть нот, лад
```

## Задачі

### MVP
1. **Послухати** й записати, що дратує.
2. **Плавна мелодія:** рух до цільової ноти кроками ±1–2 ступені, частина долей залишається паузами.
3. **Прогресії акордів** замість одного: I–VI–IV–V / i–VI–III–VII.
4. **Стерео-панорама:** додати в партитуру поле `pan` (−1..1) для голосів/шарів (`ndvi_centroid_x`; зони: захід ліворуч, схід праворуч). Узгодь з №4 (плеєр має це підтримати).
5. **Тривалість:** 30 с відео = 2.5 роки, і для слухача це швидко. Параметр `stretch` (наприклад, ×3), щоб партитура жила в «музичному часі». Узгодь з №4.

### Покращення
6. **Межа року:** окрема подія (дзвін + низька нота) на 1 січня; озвучку дати робить №4.
7. **Аномалії** (коли №1 додасть `ndvi_anomaly`): дисонанс або «тремтіння» висоти, коли весна запізнюється.
8. **Кластери екорегіонів** від №1: кожен кластер дає свій голос або інструмент.
9. **Нові звуки** (CC0, freesound.org): комахи, дощ, тундра/лід. Стиснути в `.m4a`, джерела записати в `frontend/sounds/CREDITS.md`.
10. **Тести** (`pytest`): детермінованість, ноти в гамі, гучність 0..1.

### Фінал
