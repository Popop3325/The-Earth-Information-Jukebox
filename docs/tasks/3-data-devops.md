# №3: Дані + запуск (DevOps)

**Твої файли:** `data/catalog.json`, `data/README.md`, файли деплою (`Dockerfile`, `render.yaml` тощо)
**Не чіпай:** код у `pipeline/`, `backend/`, `frontend/` (баги повідомляй власникам)

## Контекст
Ти «клей» команди: даєш реальні відео, перевіряєш, що все запускається в усіх, і викладаєш сайт онлайн. Програмувати багато не треба, ШІ допоможе з командами.

## Задачі

### MVP (перші 6 годин, бо від тебе залежать №1 і №4)
1. **Завантажити відео.** Для кожного відео з `data/catalog.json` відкрий `svs_page`, у блоці Download візьми MP4 **1080p або менше** і збережи як `data/raw/<id>.mp4`. Почни з 3 головних (обрати разом; пропозиція: `night_lights`, `iss_lightning`, `sea_surface_currents`).
2. **Записати пряме посилання** на MP4 у поле `video_url` в `catalog.json`, щоб інші могли скачати те саме.
3. **Знайти зайве на відео:** легенди, дати, логотипи. Визнач прямокутник «чистих даних» у пікселях оригіналу й запиши в `catalog.json` як `"crop": [x, y, w, h]`. Простий спосіб: зроби скріншот кадру і подивись координати в Preview на Mac.
4. **Порахувати фічі** для завантажених відео:
   ```bash
   .venv/bin/python -m pipeline.run data/raw/night_lights.mp4 --id night_lights
   ```
   Віддай №1 і №4 знахідки: що виглядає дивно.

### Покращення (12–30 год)
5. **Скрипт завантаження** `data/download.py`, що качає всі `video_url` у `data/raw/`, щоб новий учасник отримав усе однією командою.
6. **Перевірка «у всіх працює»:** пройди README з нуля на чистому клоні й виправ інструкції.

### Фінал (30–42 год)
7. **Деплой онлайн** (Render.com, Railway або Hugging Face Spaces, безкоштовно):
   - `Dockerfile` або налаштування сервісу: `pip install -r requirements.txt` → `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`;
   - відео в git не лежать: або грати їх із `video_url` (NASA), або класти стиснені версії на хостинг;
   - фічі (`data/features/*.json`) маленькі, тож для деплою їх можна закомітити (прибрати правило з `.gitignore`).
8. Перевірити посилання з телефона й іншого комп'ютера.

## Готово, коли
- ≥ 3 відео лежать у `data/raw/`, у них є `crop` і пораховані фічі
- сайт відкривається за публічним посиланням
