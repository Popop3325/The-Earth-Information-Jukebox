# №4: Музика / логіка сонифікації

**Твої файли:** `frontend/audio.js`, `shared/mapping.json`
**Не чіпай:** `frontend/app.js` та інший UI (це №2), `pipeline/` (нові фічі проси в №1)

## Контекст
Кожні 0.2 с відео є набір фіч зі значеннями 0..1 (див. `pipeline/features.py`): `brightness`, `contrast`, `saturation`, `warmth`, `edge_density`, `active_ratio`, `motion`, `centroid_x`.
- `shared/mapping.json` задає, яка фіча керує яким параметром і в якому діапазоні.
- `frontend/audio.js` (Tone.js) містить сам синтез: пад-акорд щотакту, мелодія восьмими, ударні, фільтр, реверб, панорама.
- Лад (мажор/мінор) змінюється лише на початку такту і лише якщо умова тримається `hold_s` секунд.

Головна мета: **звук має бути змістовним (видно зв'язок із даними) і приємним, а не шумом.**

## Задачі

### MVP (до 12-ї години)
1. **Послухати демо** і реальні відео від №3, записати, що дратує (одноманітність, різкість).
2. **Мелодія в гамі без «стрибків»:** зараз нота прямо відповідає яскравості. Зроби, щоб мелодія рухалась плавно (крок ±1–2 ступені до цільової ноти) і частина восьмих були паузами.
3. **Акорди, а не одна тоніка:** прогресія (I–VI–IV–V для мажору, i–VI–III–VII для мінору). Вибір акорду може залежати від фічі (наприклад, `centroid_x` або `contrast`).

### Покращення (12–30 год)
4. **«Пресети» під тип відео:** океан (м'які пади, хвилі шуму), блискавки (ударні на спалахах `active_ratio`), нічні вогні (дзвіночки), CO₂ (наростаючий дрон). Пресет можна записати в `mapping.json` як `"presets": { "<video_id>": {...} }`.
5. **Розповідь у часі:** для відео, що показують зміну за роки (нічні вогні 2012→2023, CO₂), звук має наростати: щільність, гучність, напруга.
6. **Нові фічі:** попроси в №1 `scene_cut` (акцент або тарілка на зміні сцени), `dominant_hue`, `mood_*`.
7. **API для UI** (узгодь з №2): `setVolume(db)`, `setPreset(name)`, `jukebox.mode` для відображення.

### Фінал
8. **Офлайн-рендер аудіо** (`Tone.Offline`) для 3 відео: WAV/MP3 у плейлист для подачі.
9. Дай №5 по 2–3 речення про кожне правило: «чому яскравість = гучність» тощо.

## Готово, коли
- 3 відео звучать **помітно по-різному**, і зв'язок з картинкою чути
- 5 хвилин слухати не боляче 🙂
