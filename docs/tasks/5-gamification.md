# №5: Гейміфікація

**Твої файли:** `frontend/game/` (`index.html`, `game.js`, `game.css`; оригінальний прототип лежить у `frontend/game/prototype/`)
**Не чіпай:** `frontend/player.js` (№4; потрібна зміна — попроси), backend (потрібні інші дані — проси №1)

## Контекст
Твій прототип «Леса и Нейроны» вже інтегровано в проєкт:
- `prepare.py` перенесено в `pipeline/landcover.py`, роки записано в `data/catalog.json`;
- `data.js` замінили на **`GET /api/quiz/<id>`**: `keyframes` (роки, час у відео, метрики) і `pairs` (`a`, `b`, `more`, `less`, тобто правильні відповіді);
- звуки стиснуто з 42 МБ до 1.8 МБ (`frontend/sounds/*.m4a`), звук іде з **`GET /api/score/<id>`** через спільний `ScorePlayer`;
- **`frontend/game/game.js` уже містить робочу заготовку** логіки: питання «де більше/менше птахів», прослуховування року, відкриття відрізку, підказка на пробіл, фінальне прослуховування.

Запуск: `.venv/bin/uvicorn backend.main:app --reload`, далі http://127.0.0.1:8000/game. Оригінальний прототип: http://127.0.0.1:8000/static/game/prototype/index.html. Потрібне відео `data/raw/cancun_landcover.mp4`, візьми його в №1.

## Задачі

### MVP (до 12-ї години)
1. **Перенести візуал** з `prototype/index.html` у `game/`: зоряне небо (canvas), «нейрони»-роки, світні зв'язки, іскри, дзвіночок, розмиття відео до відкриття. Логіку бери з `game.js`, дані лише з API (жодних захардкоджених років).
2. **Мова:** уся гра **англійською** (подача англійською) з перемикачем EN/UK. Озвучка (Web Speech): `en-US` / `uk-UA`. Роки вимовляються числами, словник `YEAR_WORDS` не потрібен.
3. **Виправити дизайн-баги прототипу:**
   - «режим луни» (пробіл) відкривав відрізок одразу, без спроби. Зробіть підказку лише після 1–2 помилок або за «ціну» в очках;
   - `GREEN_REF` / `ratio` більше не потрібні: гучності вже пораховано в партитурі;
   - Ctrl і CapsLock як гарячі клавіші конфліктують зі скрінрідерами (VoiceOver використовує Ctrl, CapsLock). Оберіть інші: `L` для озвучки, `Enter` для повтору.

### Покращення (12–30 год)
4. **Очки й прогрес:** зірки за відповідь з першої спроби, підсумок «ти почув, як за 31 рік зникло X% лісу» (метрики з `keyframes`).
5. **Другий рівень:** інше відео з `has_quiz: true` (попроси №3 додати `keyframes` і `quiz`, наприклад для `night_lights`: «де більше світла?»). Вибір рівня через `?video=<id>`.
6. **Режим «із заплющеними очима»:** відео приховане повністю, гра лише на слух. Це головна ідея челенджу про доступність.
7. **Доступність:** повністю з клавіатури (Tab, Enter), `aria-live` для подій, перевірка з VoiceOver (Cmd+F5).

### Фінал (30–48 год)
8. **Демо-відео ≤ 30 с** для подачі (сценарій + запис екрана зі звуком): проблема → гра → «почули, як змінилась Земля».
9. Разом із №1 зробити **подачу на сайті Space Apps**.

## Готово, коли

- гарний візуал з прототипу працює на даних з API
