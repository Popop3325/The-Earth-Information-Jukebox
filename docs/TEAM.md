## Як працювати зі ШІ (Claude, ChatGPT, Cursor тощо)

1. Склонуйте репозиторій і відкрийте папку в редакторі зі ШІ (Cursor, VS Code + Copilot, Claude Code).
2. Перше повідомлення ШІ:

   > Прочитай `README.md`, `docs/architecture.md`, `docs/TEAM.md` і `docs/tasks/<мій файл>.md`. Я учасник №N. Працюй лише з моїми файлами, дотримуйся формату з `shared/schema/features.schema.json`. Почни із задачі 1 у моєму файлі. Перед змінами коротко поясни план.

3. Кожну завершену задачу оформлюйте окремим комітом у своїй гілці і робіть PR у `main` (див. [CONTRIBUTING.md](CONTRIBUTING.md)).
