## Як це працює (коротко)

```
відео → pipeline (№1) → фічі → sonify (№2) → score.json → player.js (№4) → джукбокс (№4) і гра (№5)
                                     ▲
                   дані, crop, роки (№3)
```

Деталі: [architecture.md](architecture.md).

## Як працювати зі ШІ

1. Склонуйте репозиторій і відкрийте папку в редакторі зі ШІ (Cursor, VS Code + Copilot, Claude Code).
2. Скопіюйте **промпт із кінця свого файлу задач** і дайте його ШІ першим повідомленням.
3. Кожну завершену задачу оформлюйте окремим комітом у своїй гілці і робіть PR у `main` ([CONTRIBUTING.md](CONTRIBUTING.md)).
